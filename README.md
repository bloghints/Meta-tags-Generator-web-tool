# Meta Tags Generator (Light & Fast)
A complete, lightweight SEO & Social Media Meta Tag Generator built in a single PHP file (index.php) with a clean, responsive UI. Includes real-time Google Search (SERP) and Social Media Card (Open Graph / X) previews alongside server-side PHP generation.

✨ Key Features
Zero Dependencies (index.php): Everything—PHP logic, HTML5 markup, modern CSS, and live preview JavaScript—is self-contained in one file.
Primary SEO Meta Tags:
<title> and <meta name="title"> with live character counters and SEO length warnings (50–60 chars).
<meta name="description"> with live character indicators (120–160 chars).
<meta name="keywords">, author, and <link rel="canonical">.
Technical & Crawler Directives:
robots (index/noindex, follow/nofollow)
charset, viewport, Content-Language, revisit-after, and mobile browser theme-color (with interactive color picker).
Open Graph Protocol (Facebook, LinkedIn, WhatsApp, Discord):
og:type, og:url, og:title, og:description, og:image, og:site_name, and og:locale.
Twitter / X Cards:
twitter:card, twitter:url, twitter:title, twitter:description, twitter:image, twitter:site, and twitter:creator.
Dual Mode (Instant Live Preview + PHP Server-Side Fallback):
Updates code output and visual previews in real time as you type, and supports full POST form submission via PHP.
One-Click Copy: Copy the generated HTML <meta> block directly to your clipboard.
